## Asset validation

- MATLAB format: 5.0, little-endian.
- Internal creation timestamp: 24 January 2017.
- Variables: `irrad`, `sN2`, `sO`, `sO2`, `sO3`, `wave`.
- Each variable contains 125 double-precision values.
- Wavelength range: 7.5-360 nm.
- MATLAB element 28: exactly 121.567 nm.
- SHA256: `a98567c4f971721cec4197ad7ea17182e95df78c3a0eea880acb08fc6d560424`.
- The wavelength grid is nondecreasing, not strictly increasing: elements
  21-22 both equal 117.30308 nm. This is preserved.
- All irradiances and cross sections are finite and nonnegative.

## M4A source status

The Appendix-6 geometric heights and H2O/H2/O3 VMR columns are transcribed in
`socrates_prescribed_vmr.csv`. They are approximate SOCRATES annual, zonal,
and latitudinal climatological values intended for crude estimates: prescribed
inputs, not observations or validation truth. M4A uses SOCRATES external O3 as
an explicit substitute because no versioned CMAM O3 asset is present.

The static atmosphere is generated by NRLMSISE-00 (Picone et al., 2002) through
`pymsis==0.12.0` with `version=0`, explicit solar/geomagnetic drivers, and no
automatic space-weather retrieval. The wrapper is generation-only.

## M4C historical UV source assets

The baseline spectral backbone is a deterministic CSV reconstruction of all
six 125-element arrays in accepted `sigma.mat`: `wave`, `irrad`, `sO`, `sO2`,
`sO3`, and `sN2`. Its SHA256 is
`a398b97e7b2ae68efa9c72353444317e8a73f836870f0bd2cd6f21a5b1c7b135`.
Array equality is exact, including duplicate source elements 21--22 at
117.30308 nm and MATLAB element 28 at 121.567 nm. Irradiance is interpreted as
photon cm-2 s-1 per tabulated spectral element; no wavelength-bin factor is
applied. This is a project-local 2017 inheritance, not a claim that the
spectrum itself is an exact Li-2020 or JPL18 product.

JPL Publication 15-10 / Evaluation 18 (2015), supplied reference-copy SHA256
`149a4bab985402c67419e02ff8ca80202d1ba55f5383fbf69692e2184b68da08`,
was inspected at printed pages 4-43 and 4-47. M4C packages:

- a corrected transcription of all 98 H2O Table 4B-3 rows, 121--198 nm, asset SHA256
  `d70d7d79405cb4b86de2186d1fd1212c332eb1eb362279f117b99daa00ce2e2c`;
- all 33 H2O2 Table 4B-5 rows, 190--350 nm, asset SHA256
  `bec01ae613d088455bdb64657b46f33bfe3cdb3b6e294c6f41fd21cbd611f4a1`;
- the exact Table 4B-6 temperature-polynomial coefficients in metadata and
  code. The deterministic generator validates both historical source hashes.

JPL18 prints `199 nm -> 1.08e-20 cm2 molecule-1` between the 188 and 190 nm
rows. The asset retains the cross section at the corrected wavelength 189 nm.
This is classified as a typographical correction because the printed row is
sequentially misplaced, 199 nm lies outside the stated 121--198 nm range, and
the table notes use one source for 183--191 nm. JPL20 Table 4B-2-2 prints
`189 nm -> 1.08e-20 cm2 molecule-1` and is used solely as corroboration. The
machine-readable correction record preserves JPL18 as the numerical source.

The two H2O branching arrays are historical_2020 reduced two-channel yields
based on the frozen Brasseur/JPL-informed model approximation; they are not
claimed to be exact JPL18 quantum yields.

## Inputs still not present

Future excitation work still needs versioned numerical inputs for:

- HITRAN data used to construct `gA`, `gB`, and `gIRA`;
- a versioned CMAM external-ozone profile matching Li-2020 provenance.

JPL Evaluation 20 supplied here will not silently substitute for those inputs.
Apart from its nonnumerical corroboration of the 189 nm correction, it is
inventory/future-reference material only and is excluded as a numerical source
from both `legacy_2017` and `historical_2020`.
